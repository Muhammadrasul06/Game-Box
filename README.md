# Arcade Game Hub

Arcade Game Hub is a web-based arcade platform that brings multiple small games into one clean and simple hub. The project is built for the browser and focuses on fast access, simple gameplay, responsive design, and a modern dark/neon visual style.

The main idea of this project is to create a lightweight game collection where users can open the website, choose a game, play quickly, restart easily, and switch between games without needing to install anything.

## About the Project

This project is designed as a mini-game hub rather than a single game. Each game has its own gameplay style, controls, and screen, but everything is connected through one main menu. The hub includes playable games, locked “Coming Soon” cards, global settings, and a consistent arcade-style interface.

The project is still in development. Some parts are already playable, while other games and features are planned for future updates.

## Main Goals

- Build a browser-based arcade game hub
- Keep the experience simple and easy to use
- Add multiple small games inside one project
- Make each game replayable and fun
- Support desktop and mobile layouts
- Keep the UI clean, modern, and responsive
- Improve gameplay, physics, controls, and visuals over time

## Core Features

- Main game selection hub
- Playable game cards
- Coming Soon game cards
- Dark/neon arcade interface
- Restart and back-to-menu flow
- Responsive layout for different screen sizes
- Keyboard, mouse, and touch-friendly controls where needed
- Global settings such as sound and visual preferences
- Modular structure for adding new games later

## Current Status

Arcade Game Hub is an active development project. The current focus is on making the core games stable, playable, and enjoyable before adding more advanced features.

Future updates may include more games, improved mobile support, better animations, smoother physics, score saving, unlockable content, and improved UI polish.

## Planned Direction

The long-term plan is to turn this project into a bigger arcade-style web platform with different types of games, such as classic arcade games, action games, racing-style games, physics games, puzzle games, and survival-style mini-games.

The project is not trying to be a large AAA game. The goal is to create a fun, lightweight, browser-friendly arcade hub that can grow step by step.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
